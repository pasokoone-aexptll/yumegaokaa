# 問い合わせ・情報開示の運用

2026-11-25ユーザー確定。窓口support@dreamcloud.sh。料金は無料。メール自動削除機能を実装したという意味ではない。

- メールと対応記録は対応完了日を記録し、90日後に削除する。転送先、送信済み、添付の作業コピーも対象。未対応・対応中は必要な範囲で保持し、不要になった情報を溜めない。
- 運営者氏名・住所の開示請求は遅滞なく回答する。回答用の正式情報は運営者が非公開で管理し、リポジトリに書かない。運営者情報を請求するだけの相手へ不要な身分証提出を求めない。
- 利用者本人のデータ開示・削除は、必要な範囲で本人または代理権を確認する。ログイン用OTPやパスワードを送らせない。
- 保護者の否認・撤回は関係と対象アカウントの確認後に停止・退会削除案内。確認前に利用者の投稿や位置を開示しない。
- 通報証拠は退会時原則削除。法令上の保存義務等が具体的に発生した場合のみ、対象・理由・期限・権限を個別に判断する。現行コードに一般的なlegal hold機能はないため、抽象的な安全目的で自動的に保持しない。
- 削除処理が失敗した場合は清掃jobを確認し、完了を確認してから回答する。バックアップからの即時物理消去を約束しない。

公開前の実作業：受信・返信試験、削除期限を忘れず処理する担当者の運用開始、実際のメールサービスの保存仕様の照合。
