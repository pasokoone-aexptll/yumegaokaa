## 1. 運営者と連絡先

DreamCloudは「電信出口」で扱う個人情報を以下のとおり取り扱います。

サイト上の運営者表記：DreamCloud。運営者の氏名・住所は、ご請求に応じて遅滞なく回答します。開示請求は下記窓口へご連絡ください。

お問い合わせ：support@dreamcloud.sh

## 2. 取り扱う情報と目的

| 情報 | 使用目的 |
| --- | --- |
| メールアドレス、アカウント識別子、認証に関する情報 | ログイン、アカウント管理、不正利用防止 |
| 表示名、プロフィール画像 | プロフィールと投稿者の表示 |
| チャット本文、PINの内容・座標・参加状況、共有pool画像 | 街の交流、投稿・画像の共有、気配の表示 |
| 招待・入街・退出・操作の記録 | 登録、滞在状態の管理、重複操作の防止 |
| 年齢区分、保護者同意を得た旨の申告、申告日時、説明文の版 | 利用条件の確認、申告内容の管理 |
| 通報、証拠、ブロック、問い合わせと対応記録 | 安全管理、相談・権利請求への対応 |
| 通知トークン、配信に必要な情報 | 許可された端末への通知 |
| 不正利用防止・障害対応に必要な操作・通信記録 | 安定運用と安全確保 |

プロフィール画像に顔写真は必要ありません。共有pool画像は他の利用者の気配表示にも使われます。カメラは招待QRの読み取りに、写真へのアクセスは画像の選択に使用します。

## 3. 位置情報

入街中は、アプリが背景にある間も端末の位置を観測し、街内外や区画を判定します。気配更新ではGPSの生座標ではなく、区画・観測時刻等をサーバーへ送信します。PINに指定した座標は別途保存・共有します。ゴースト中も街内の滞在を確認しますが、気配の区画は送信しません。

端末設定で権限を変更できます。許可を取り消すと、位置を必要とする機能が利用できなくなる場合があります。

## 4. 他の利用者への表示

チャットの表示名・プロフィール画像・本文、PIN・参加状況等は登録済み利用者へ表示します。気配の表示では名前や個人IDを公開しませんが、投稿・入街ログ等との時刻の対応から本人が推測される可能性があります。完全な匿名性は保証しません。メールアドレス、年齢区分、同意申告、通報内容は通常の利用者向け表示には含めません。

## 5. 13〜17歳の利用

13歳未満の方は利用できません。13〜17歳の方には、保護者に規約・本ポリシーを確認してもらい、同意を得た旨を申告していただきます。年齢は「13歳未満／13〜17歳／18歳以上」から選択します。生年月日・保護者メールは収集せず、保護者への確認メールも送りません。記録は保護者本人の認証を示すものではありません。登録時の年齢区分・申告記録はアカウント利用中に保存し、退会時に削除します。

保護者から同意の否認・撤回があった場合は、申出者と対象アカウントを確認したうえで利用を停止し、退会・削除を案内します。関係を確認する前にアカウントの情報を開示しません。

## 6. 保存期間と退会時の削除

| 情報 | 保存・削除方針 |
| --- | --- |
| チャット | 30日表示し、その後24時間以内に削除 |
| PIN | 作成から24時間で失効し、失効・削除から24時間以内に本文・座標・参加情報を削除 |
| 気配 | 10分で非公開とし、失効から1時間以内に稼働中のDBから削除 |
| 未公開の準備画像 | 準備開始から24時間で削除対象 |
| 滞在・入街試行の記録 | 終了から24時間 |
| 入街ログ | 30日 |
| 不正利用防止用の制限記録 | 7日 |
| 運営操作の監査記録 | 90日 |
| 通報証拠 | 対応完了後30日、未対応は最長180日。【確定待ち：退会後も保持する必要性・根拠と対象】 |
| 問い合わせ記録・配信／基盤ログ | 【確定待ち：実際の設定と必要な保存期間】 |

退会時は利用資格を停止し、プロフィール、本人のチャット・PIN本文、年齢区分・同意申告を削除します。投稿の削除状態は通常の清掃期限まで残ります。画像・認証情報は順次削除処理を行います。【確定待ち：認証情報の残存項目、画像等の削除完了までの期間】

バックアップに含まれる情報は【確定待ち：バックアップの保持期間と復元時の削除方法】に従って消去します。退会直後にすべての保存先から消えるとは限りません。

## 7. 委託先・外部サービスと第三者提供

認証、データ・画像保存、メール、通知、地図、通信のため外部サービスを使用します。【確定待ち：本番で使用する事業者名、各送信情報・目的、保存国、国外での取扱いと保護措置】

本ポリシーで説明する利用者間の共有・業務委託のほか、法令で認められる場合を除き、本人の同意なく個人データを第三者へ提供しません。国外への提供がある場合は、適用される法令に従い、必要な情報提供・同意取得または保護措置を実施します。

## 8. 安全管理

情報へのアクセスを必要な担当者に限定し、認証・アクセス制御等で情報を保護します。【確定待ち：本番構成に即した組織的・人的・物理的・技術的措置と国外環境の把握についての案内】

## 9. 情報の確認・訂正・削除等

アプリのアカウント画面から退会できます。ログインできない場合や、個人情報の利用目的の通知、開示、訂正、利用停止・消去等の請求は、support@dreamcloud.shへご連絡ください。必要な範囲で本人または代理権を確認し、適用される法令に従って対応します。対応できない場合は理由を説明します。認証コードやパスワードをメールで送らないでください。

【確定待ち：請求手続の公開先・回答方法・手数料を設ける場合の額。現時点で料金徴収は未決定】
