# 電信出口 プライバシーポリシー


## 1. 運営者と連絡先

DreamCloudは「電信出口」で扱う個人情報を以下のとおり取り扱います。

サイト上の運営者表記：DreamCloud。運営者の氏名・住所は、ご請求に応じて遅滞なく回答します。開示請求は下記窓口へご連絡ください。

お問い合わせ：support@dreamcloud.sh

## 2. 取り扱う情報と目的

| 情報 | 使用目的 |
| --- | --- |
| メールアドレス、アカウント識別子、認証に関する情報 | ログイン、アカウント管理、不正利用防止 |
| 表示名、プロフィール画像 | プロフィールと投稿者の表示 |
| チャット本文、PINの内容・座標・参加状況、共有pool画像 | 街の交流、投稿・画像の共有、気配の表示 |
| 招待・入街・退出・操作の記録 | 登録、滞在状態の管理、重複操作の防止 |
| 一般公開版の登録で申告する年齢区分、保護者同意を得た旨の申告、申告日時、説明文の版 | 利用条件の確認、申告内容の管理 |
| 通報、証拠、ブロック、問い合わせと対応記録 | 安全管理、相談・権利請求への対応 |
| 通知トークン、配信に必要な情報 | 許可された端末への通知 |
| 不正利用防止・障害対応に必要な操作・通信記録 | 安定運用と安全確保 |

プロフィール画像に顔写真は必要ありません。共有pool画像は他の利用者の気配表示にも使われます。カメラは招待QRの読み取りに、写真へのアクセスは画像の選択に使用します。

## 3. 位置情報

入街中は、アプリが背景にある間も端末の位置を観測し、街内外や区画を判定します。気配更新ではGPSの生座標ではなく、区画・観測時刻等をサーバーへ送信します。PINに指定した座標は別途保存・共有します。ゴースト中も街内の滞在を確認しますが、気配の区画は送信しません。

端末設定で権限を変更できます。許可を取り消すと、位置を必要とする機能が利用できなくなる場合があります。

## 4. 他の利用者への表示

チャットの表示名・プロフィール画像・本文、PIN・参加状況等は登録済み利用者へ表示します。気配の表示では名前や個人IDを公開しませんが、投稿・入街ログ等との時刻の対応から本人が推測される可能性があります。完全な匿名性は保証しません。メールアドレス、年齢区分、同意申告、通報内容は通常の利用者向け表示には含めません。

## 5. 13〜17歳の利用

一般公開版は13歳以上を対象とします。13〜17歳の方には、保護者に規約・本ポリシーを確認してもらい、同意を得た旨を申告していただきます。年齢は「13歳未満／13〜17歳／18歳以上」から選択します。生年月日・保護者メールは収集せず、保護者への確認メールも送りません。記録は保護者本人の認証を示すものではありません。登録時の年齢区分・申告記録はアカウント利用中に保存し、退会時に削除します。

保護者から同意の否認・撤回があった場合は、申出者と対象アカウントを確認したうえで利用を停止し、退会・削除を案内します。関係を確認する前にアカウントの情報を開示しません。

## 6. 保存期間と退会時の削除

| 情報 | 保存・削除方針 |
| --- | --- |
| チャット | 30日表示し、その後24時間以内に削除 |
| PIN | 作成から24時間で失効し、失効・削除から24時間以内に本文・座標・参加情報を削除 |
| 気配 | 10分で非公開とし、失効から1時間以内に稼働中のDBから削除 |
| 未公開の準備画像 | 準備開始から24時間で削除対象 |
| 滞在・入街試行の記録 | 終了から24時間 |
| 入街ログ | 30日 |
| 不正利用防止用の制限記録 | 7日 |
| 運営操作の監査記録 | 90日 |
| 通報証拠 | 対応完了後30日、未対応は最長180日。ただし通報者または対象利用者の退会時には、関連する通報内容・証拠を原則削除 |
| 問い合わせ記録 | 対応中は必要な範囲で保存し、対応完了から90日でメールと対応記録を削除 |
| SupabaseのAPI・DB基盤ログ | 現行Freeプランの閲覧保持期間は1日 |
| Renderのアプリ稼働ログ | 現行Hobbyプランでは7日 |
| Resendの認証メール・配信ログ | 標準の保存期間は30日。提供元のバックアップは7日 |

退会時は利用資格を停止し、プロフィール、本人のチャット・PIN本文、年齢区分・同意申告を削除します。投稿の削除状態は通常の清掃期限まで残ります。画像・認証情報は順次削除処理を行います。退会後の定期処理で画像と関連記録を整理し、認証アカウントを削除します。処理が失敗した場合は再試行し、未完了のまま削除済みとは扱いません。

DBと画像のバックアップは暗号化して非公開の保管先に保存し、保存から7日後に削除対象になる自動ルールを設定しています。期限到達と実際の削除には処理時間の差があります。バックアップを復元する場合は、隔離した環境で退会・削除の状態を照合します。削除済み情報の除去を確認するまではサービスを再開しません。退会直後にすべての保存先から消えるとは限りません。

## 7. 委託先・外部サービスと第三者提供

本サービスと公式サイトでは、次の外部サービスを使用します。

| サービス | 情報・利用目的 | 保存・処理場所等 |
| --- | --- | --- |
| Supabase | 認証メールアドレス、アカウント、投稿、画像、区画情報等の認証・DB・画像保存 | 主な保存先は東京。運用・支援等ではシンガポール・米国等で処理される場合があります |
| Render | 認証の照会、街の更新の配信、削除・通知処理と稼働ログ | 米国オレゴンのサーバーを使用 |
| Resend | 認証メールの宛先・本文・配信記録 | 認証メールの送信。提供元と再委託先で国外処理される場合があります |
| Cloudflare R2 | 暗号化したDB・画像バックアップ | 非公開のアジア太平洋地域の保管先。日本国内限定ではありません |
| Cloudflare Email Routing・Googleのメールサービス | 問い合わせの送信者・本文・添付と対応メール | 問い合わせの転送・受信・保管。事業者のグローバル基盤を使用 |
| Vercel | 公式サイトへのアクセス時のIPアドレス・URL・時刻・ブラウザ情報等 | サイト配信・セキュリティ。グローバル配信基盤を使用 |
| Apple Maps | 地図表示に必要な地図リクエスト等 | iOSの地図表示。Appleによる取扱いは同社のプライバシー説明に従います |
| Apple Push Notification service | 通知トークン・配信内容 | iOSの通知を配信する際に使用します |

公式サイトに独自の広告・アクセス解析タグは設置していません。ホスティング事業者による配信・不正利用防止等の処理はあります。問い合わせ記録の90日削除は運営者が管理するメールと対応記録に適用し、提供元側のバックアップ等には各サービスの削除処理が適用されます。

提供元の取扱い・保護措置は、[Supabase](https://supabase.com/legal/privacy-resources/data-residency-and-transfers-faq)、[Render](https://render.com/dpa)、[Resend](https://resend.com/security/gdpr/)、[Cloudflare](https://www.cloudflare.com/privacypolicy/)、[Google](https://policies.google.com/privacy)、[Vercel](https://vercel.com/legal/privacy-notice)、[Apple](https://www.apple.com/legal/privacy/)で確認できます。外国での取扱いや保護措置についてのお問い合わせも、下記窓口で受け付けます。

本ポリシーで説明する利用者間の共有・業務委託のほか、法令で認められる場合を除き、本人の同意なく個人データを第三者へ提供しません。国外への提供がある場合は、適用される法令に従い、必要な情報提供・同意取得または保護措置を実施します。

## 8. 安全管理

運営者が個人情報の取扱いを管理し、問い合わせ・削除依頼に対応します。担当者は利用目的に必要な範囲でのみ情報を取り扱い、端末・認証情報を適切に管理します。サーバーの管理資格をアプリや公開サイトに含めず、通信の暗号化、利用者ごとのアクセス制御、非公開の画像保管、暗号化バックアップを使用します。バックアップの復号鍵は別に管理します。

委託先の公開する安全管理・再委託先・国外処理に関する情報を確認し、構成変更時にも取扱いを見直します。事故が発生した場合は影響を確認し、法令に従って必要な報告・本人への通知等を行います。

## 9. 情報の確認・訂正・削除等

アプリのアカウント画面から退会できます。ログインできない場合や、個人情報の利用目的の通知、開示、訂正、利用停止・消去等の請求は、support@dreamcloud.shへご連絡ください。必要な範囲で本人または代理権を確認し、適用される法令に従って対応します。対応できない場合は理由を説明します。認証コードやパスワードをメールで送らないでください。

請求窓口は[お問い合わせページ](https://hello.dreamcloud.sh/support/)です。原則としてご連絡いただいたメールへ回答し、法令上必要な開示方法の指定がある場合はその方法に従って対応します。手数料は無料です。
