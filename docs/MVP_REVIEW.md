# 現行MVPのリスク・確認点

更新：2026-10-29。現在の合意を踏まえたレビュー。対策の具体方式は未承認。[旧レビュー](history/MVP_REVIEW_BEFORE_2026-10-29_AUDIT.md) は履歴。

| 論点 | 現在の扱い・残るリスク |
| --- | --- |
| 気配と個人追跡 | 最新1件・短命・公開集約でも、入街ログや少人数からの推測は残る。完全匿名とは説明しない |
| 端末の虚偽 | トークンは操作資格であり現地証明ではない。静的NFCもコピー・再送可能。改造端末の位置申告を完全には検証できない |
| 終了と通信 | 退出・失効後の復活、逆順・二重加算を防ぐ。オフライン退出の即時サーバー反映は保証しない |
| 保存 | 上書きした最新行もDBログ・バックアップに過去値が残り得る。アプリの位置履歴非保存だけで全保存層の非保存を保証しない |
| 公開内容 | 招待参加者も募集地点・会話・予定を保存できる。削除で第三者の記録を取り消せない |
| 迷惑行為 | 招待だけでは防げない。合意済みの制限、本人・運営権限、通報対応が必要。通報数だけで永久停止しない |
| イベント | 最後の1席の同時申込、取消と編集、通知失敗、参加者名の漏出を扱う |
| タグ管理 | 物理書込とサーバー有効化は同時確定できない。途中失敗の状態、再読込確認、保護方式はQ06 |
| 背景測位 | iPhone歩行は初回確認済み。静止中変更・電池効率は未確認。OS欠測を許容し10分で消す |
| 文化 | 機能が動くことと「孤独でなく、関係に縛られない」を実現できることは別。架空の人数や参加圧力で補わない |

現行要件に対する確認条件は [ACCEPTANCE](ACCEPTANCE.md)。技術の一次資料は旧レビューと [TECH_VALIDATION](TECH_VALIDATION.md) に残すが、過去の調査を最新バージョンの互換性保証にしない。技術選定時に公式資料で再確認する。
