## 2026-11-05の追加UI修正

ユーザー依頼に基づき、地図移動中のチャット本文をopacity 0.25へ減光し、停止後に戻す。nativeぼかしには親alphaを掛けない。タブは再タップ時も拡大して戻り、募集/イベント/気配はタップ時の拡大と軽いhapticを接続。ヘッダーの街名テキストfallbackは既存DreamCloudロゴへ置換（池袋専用素材は維持）。通信ダイアログとバナーの操作ボタンは白。

Homeの既存pull更新は短い/空の一覧でも引けるよう明示し、手動更新は進行中の自動取得を待たず最新リクエストを開始。古い応答はrequest番号で棄却する。オフラインの利用資格取得失敗後はログイン済み利用者のタブを表示するが、認可状態をactiveに書き換えず、既知の未登録/初回設定/停止/退会等は従来どおり非表示。

整理：タップアニメーションをuseTapPulseへ共通化、UIプレビューの状態描画をdebug/UIPreviewScenarioへ分離、Mapの配置ハンドルを使わないときのカメラ更新再描画とMapHeaderの未使用styleを除去。原本素材・検証証拠・隔離試作は保持。全ページモックの完成や本番公開準備の完了ではない。

型/Lint、タブ表示21 assertion、利用資格通信失敗/復旧/セッション分離、Home手動更新競合/失効テストは成功。新しいアニメーション・haptic・pull操作とオフライン起動のiPhone確認は未完。

## デバッグ入口

開発ビルドのログイン画面「開発用 UIプレビュー」、またはSettings「開発用 → UIプレビュー」。`/ui-preview`。Releaseは専用表示のみで利用不可。

`src/components/debug/catalog.ts`に製品27ルートを登録。通常画面へのリンクは通常認可を維持し、**実操作**となる。イベント/募集/ステッカーは実際の対象IDが必要。入街・位置選択・通報は呼出元の文脈が必要なため元の操作から開く。

### モックで再現できる範囲

実表示部品 `StreetLogin` / `MapStatusBanner` / `MapErrorDialog` / `EntryAnimation` を利用。

1. ログイン
2. OTP
3. ログイン通信エラー
4. 認証中
5. 自動終了通知バナー
6. チャット取得失敗→再読み込み中→成功
7. チャット取得失敗→再読み込み中→失敗
8. 通信エラーダイアログ
9. 投稿制限バナー
10. 入街待機
11. 入街記録中
12. 入街成功

モック操作は認証・投稿・DB・位置観測を実行しない。画面のプレビューであり、OSのネットワーク切断、通信再送、サーバー復旧の試験ではない。既に動いているアプリの背景観測等を停止するモードでもない。

**未完：全27ページのデータ付きモック表示。** 現時点で索引と12状態プレビューまで。ページごとの読み込み・空・失敗・権限・競合状態を注入する分離adapterが必要。索引を全ページのモック完成とみなさない。実認証や本番native adapterをグローバルに偽装する方式は採っていない。
