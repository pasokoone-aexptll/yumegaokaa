残る限界：技術構成・公開集約・認証・削除詳細など未決定事項は残る。文書が整理済みでも製品の設計完了・実装完了を意味しない。生座標を送るか、参加登録の削除時期などをエージェントが決めて埋めてはいない。技術の最新互換性・価格は今回再調査せず、技術選定時に確認する。
