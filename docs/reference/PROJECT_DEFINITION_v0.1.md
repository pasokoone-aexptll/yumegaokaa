# yumegaoka — Project Definition v0.1

**誰とも親密にならず、誰にも気を遣わず、それでも一人ぼっちにはならない。**

## 01. Vision — 実現したい世界

人々が特定の人間関係に依存することなく、同じ空間に存在する他者を感じながら、自由に過ごせる世界を実現する。

人とつながるために、友達になる必要はない。

誰かと約束する必要も、会話する必要もない。

ただ、その街へ行けば誰かがいる。

そのような空間を、ソフトウェアと現実の街を通じて実現する。

## 02. Customer — 初期顧客

**通話界隈民**

特に以下の特徴を持つ人々。

- 日常的にオンラインで通話する
- 特定の相手に限定されない交流を好む
- 継続的な人間関係の維持に負担を感じる
- 誰かと一緒にいたいが、親密な関係を必ずしも求めていない
- オフラインでの交流にも関心がある

初期市場は、池袋で交流する通話界隈民の小規模コミュニティとする。

## 03. Problem — 解決する課題

**人とつながっていたいが、そのために特定の人との関係を維持しなければならない。**

既存のSNSでは、交流がアカウント同士の関係や、投稿・通話・メッセージを中心に成立している。

そのため、他者の存在を感じたいだけでも、誰かを誘ったり、通話を募集したり、関係を維持したりする必要が生じることがある。

顧客が求めるのは、必ずしも友達を増やすことではない。

**人間関係を維持する義務を負わずに、他者と空間を共有できること。**

## 04. Solution — 提案する解決策

**街ドメインの位置情報共有アプリと、それを基盤とする「夢ヶ丘界隈」の形成。**

yumegaokaは、ユーザーではなく街を中心とするソーシャルプラットフォーム。

ユーザーは街に接続し、その街にいる人々の存在を感じられる。

街の参加者同士は、友達にならなくても同じ空間を共有できる。

位置情報は本人の同意に基づき、公開範囲と期限を制限する。相手を特定して追跡することではなく、街に人が存在することの可視化を基本とする。

### Core Experience

1. 暇になったら夢ヶ丘を開く。
2. 街に誰かがいることを知る。
3. 特定の誰かと約束せずに街へ向かう。
4. その場で好きなように過ごす。
5. 好きなときに帰る。

これによって「街に行くこと」自体が、オンラインの通話に参加するような日常的な選択肢になる。

## 05. Strategy — 文化形成の戦略

**Culture First, Software Second.**

### Phase 1 — コミュニティへの参加
通話界隈の人々と交流し、相互に信頼できる関係を築く。

### Phase 2 — オフ会の形成
友人同士でオフライン交流を行い、街に集まる習慣を形成する。

### Phase 3 — プロダクトの導入
街に接続し、他者の存在を感じられるアプリとしてyumegaokaを提供する。

### Phase 4 — 日常化
特別なオフ会がなくても、自発的に街へ集まる人々を増やす。

### Phase 5 — 自律的な拡散
友人の紹介やSNS上での共有によって、新しい参加者が加わる。

### Phase 6 — 文化の成立
特定の場所に継続的な交流文化が生まれ、その場所が「夢ヶ丘」と呼ばれるようになる。

## 06. Product Principles — 設計原則

- **Place First:** 人間関係よりも場所を中心にする。
- **Ambient Presence:** 会話しなくても他者の存在を感じられる。
- **Low Commitment:** 参加や退出に社会的な負担を生じさせない。
- **Optional Intimacy:** 親密になる自由も、ならない自由も尊重する。
- **Privacy by Design:** 居場所の公開は本人が制御できる。
- **Culture over Engagement:** アプリの利用時間より、現実の空間で生まれる体験を重視する。

## 07. Success — 成功の定義

夢ヶ丘の成功は、アプリのダウンロード数だけでは測れない。

成功とは、創設者がいなくても人々が自発的に街に集まり、参加者が入れ替わりながら、そこに継続的な文化が存在すること。

そして、その街に行けば誰かがいるという安心感が、参加者に共有されること。

## 08. Hypothesis — 検証すべき中心仮説

**通話界隈で確認された「関係を固定せずに他者とつながりたい」という欲求は、現実の街でも成立し、場所を中心とするソフトウェアによって持続的な交流文化へ発展させられる。**

この仮説を、小規模な実地実験と利用者の行動観察によって検証する。
