# 電信出口 問い合わせ・アカウント削除案内（公開用草案）

> 未公開。窓口の受信・返信試験、削除処理とプライバシーポリシーの未確定項目を確認してから掲載する。フォーム実装や即時対応を約束する原稿ではない。

## お問い合わせ

電信出口へのお問い合わせは support@dreamcloud.sh へお送りください。問題が起きた画面、操作、日時、端末の種類が分かると確認に役立ちます。パスワードやログイン用の認証コードは送らないでください。

問題のある投稿や利用者についてはアプリ内の通報・ブロックも利用できます。

## アカウントを削除したいとき

アプリのアカウント画面から退会できます。アプリを削除するだけではアカウントは削除されません。

ログインできない場合やWebから削除を依頼する場合は、登録したメールアドレスから support@dreamcloud.sh へ、件名「電信出口 アカウント削除依頼」でご連絡ください。登録メールを利用できない場合も窓口へ相談してください。なりすましによる削除を防ぐため、対象アカウントの確認後に対応します。

削除対象、例外として残る情報、完了までの期間は[プライバシーポリシー](https://hello.dreamcloud.sh/privacy)をご確認ください。【公開前に同ポリシーの未確定欄を解消】

## 保護者の方へ

利用対象は13歳以上です。13〜17歳の利用者は、保護者の同意を得ていることを登録時に申告します。保護者ご本人をメールで認証する方式ではありません。

同意していない、または同意を撤回したい場合は窓口へご連絡ください。申出者と対象アカウントの関係を確認後、利用を停止して退会・削除を案内します。確認前に利用者の投稿・位置などの情報を開示しません。初回のメールに身分証などを添付する必要はありません。必要な確認方法を個別に案内します。
