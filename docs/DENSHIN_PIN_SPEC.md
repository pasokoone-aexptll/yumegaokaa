# 電信PIN — 採用仕様と画面契約

更新：2026-11-19。ユーザーの概念統合依頼、8項目の推奨案への基本同意、街外からの作成・1日3個・作成後の募集ON/OFF指定と添付Figmaを根拠とする。**仕様更新のみ。コード・DB・実機には未反映。** R12/R13/R14/R16/R17/R19に対応。旧募集・オフ会を置換し、旧33タスクのDONE履歴は保持する。

## 採用済み

- 電信PINは地図上の地点に挿すステータスメッセージ。題名・説明・開催日時を分けず、必須本文のみ最大500文字。日時は本文で伝える。
- 招待登録済み会員が利用。街の外にいる、未入街、ゴースト中でも作成可能。配置先は対象の街の範囲内。ユーザーの居場所と配置可能範囲は別条件。
- 1人1日3個まで作成。同時3件の推奨案も維持。日付境界と削除後の作成枠はQ-DP02で確認する。
- 作成受理から24時間で全モード共通に失効し、地図・Home・参加中一覧から消える。編集、募集切替、参加、到着で期限を延長しない。退出・滞在失効・端末切替・ゴースト切替には連動させない。
- 作成者は本文編集、募集ON/OFF、手動削除が可能。削除は確認を挟む。終了済みPINを復活させない。
- 募集モードOFFはメッセージとして表示し、参加ボタンは出さない。ONは作成者以外に参加を提供する。後からON/OFF可能。「参加者がいればOFF不可」という前回推奨は最新指示で撤回。OFF時の既存参加者の扱いはQ-DP01。
- 最大募集人数は募集モードと独立したON/OFF設定。上限OFFは無制限。上限ONでは参加予定＋現地にいる参加者の合計を数え、作成者は含めない。満員なら参加不可。定員を現在人数未満に下げられない。設定可能範囲・初期値はQ-DP03。
- 他人は「参加する」→参加予定→「現地につきました」→現地にいる、の順に移る。二重計上しない。到着は自己申告でGPS/NFC認証は不要。参加予定から取消、到着後は「離れる」で抜けられ、空席が戻る。
- 作成者は参加ボタンを押さずホストとして別枠管理。自分の到着も申告可能。未申告なのに現地にいる人へ自動掲載しない。
- 参加者の名前・本人プロフィール画像は、PINを閲覧できる会員全員に公開。現地にいる人と参加予定を分け、ホストを識別する。過去の参加履歴は作らない。
- 参加・到着は街への入街や気配人数を変更しない。ゴースト中でもPINの本人名・参加名は匿名化しない。
- 参加者がいる間の場所変更は不可、本文変更は可能。参加者なしでは地図から場所変更可能。公開地点は移動に追従しない。
- 参加中のPINの本文変更・削除を通知対象とし、通常の24時間失効は通知しない。既存のアプリ内通知＋Push経路を利用する。募集OFF時の通知はQ-DP01に含む。
- Homeの自分のPIN・参加中のPINへの導線を維持する。Figmaの一覧分類との統合はQ-DP04で確認。
- 終了後は本文・座標を取得対象外とし、本文・座標・参加情報を終了から24時間以内に削除する既存保持方針を引き継ぐ。通報証拠は別権限・別期限。日次上限の最小記録は削除で上限回避を起こさない設計が必要。
- 認可・満員・日次上限・失効をサーバーで検査し、競合で超過させない。同じ操作の再送で二重作成・枠の二重消費・取消や終了後の復活を起こさない。

## Figmaから読む画面と遷移

参照原本：`docs/reference/denshin-pin/Group 740.png`（他人から見た状態）、`Group 741.png`（作成者）。画像内の名前・本文・人数・招待残数はサンプルで、実データや追加要件ではない。ヘッダーロゴ変更・招待仕様変更・予約実行機能まで採用したとは扱わない。

1. Home一覧→本文の行から詳細、位置確認からMap上の対象PINへ。Homeの＋→作成シート。
2. Mapの通常PINは画像＋本文吹き出し。募集ONでは募集の立体オブジェクト、募集表示、本文、名前、人数/定員、アバター列を組み合わせる。PIN画像に本人画像と街pool画像のどちらを用いるかはQ-DP05。
3. PINタップ→地図を背面に残した半高のぼかしシート。閉じるボタンと取っ手があり、上へ広げると詳細・名簿を表示する。
4. 他人の募集OFF詳細は画像・本文・作者名。募集ON詳細は募集表示、人数、現地にいる人、参加予定、状態に応じた下部操作を追加。
5. 「参加する」成功→チェック印の参加確定表示→詳細では「現地につきました」。確定表示はサーバー成功後のみ。失敗・満員では成功演出を出さない。閉じて地図/詳細へ戻れる。演出秒数は未固定。
6. 自分の詳細は「自分」、募集モードスイッチ、編集ボタン。募集ON時は名簿も表示。スイッチから後でON/OFFできる。
7. ＋から作成、鉛筆から既存値入りの編集シート。本文、人数上限スイッチ、数値操作、募集スイッチ、「マップを挿入／変更する」、閉じる、保存チェックを配置。編集時は見出しを「電信PINを編集」にする。
8. 場所選択→既存Mapで配置→完了→入力を保持した作成/編集へ戻る。保存までは公開内容を変更しない。画像にある数値12や2種類の数値UIは初期値・厳密操作の確定根拠にしない。

取消・離脱・削除・満員・上限到達・送信中・失敗・失効の画面は添付にないが、採用機能を操作可能にする必要がある。未提示だから省略しない。本文500文字を地図で全表示せず、詳細で全文を読めるようにする（省略寸法は実装時調整）。
