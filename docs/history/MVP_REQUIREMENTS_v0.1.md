## 2. 目的・対象・範囲

### 2.1 目的

現実の街で他者の存在を感じ、特定の人間関係を維持する義務を負わず、参加・退出できる空間を作る。アプリ普及自体ではなく、現実の「夢ヶ丘」という文化の成立を目指す。

MVPは通話界隈のオフ会で利用し始める。オフ会ピンが集合のきっかけを作り、人数・チャットが街の様子を伝え、募集ピンが現地での合流を支える。

### 2.2 対象

- 初期利用者：招待された通話界隈の人々。
- 初期実験場所：池袋を想定。
- 利用者アプリ：iOS・Android。
- 運営：プロジェクト所有者。運営用クライアントも必要。
- リリース順序、試験人数、対応OSバージョン、運営クライアントの形態は未決定。

### 2.3 MVPの構成

中心機能は街へのイン／アウト、街ローカルチャット、ピン、街の様子を表示するマップ。これを支える招待・アカウント・QR引き継ぎ・通報／制限・運営機能を含む。

リアルタイムで個人の位置を追い続ける共有機能は不要。人数は正確な実在人数ではなく、有効なチェックイン数による賑わいの目安。複数端末による人数水増し対策はMVPで考慮しない。

DM、フレンド、通知、独自3D街モデル等は過去の候補であり、MVPに採用されたとは扱わない。画像中の文字・API名・人物表示は新たな要件の根拠にしない。

## 3. 利用者と権限

| 操作 | 未チェックインの参加者 | チェックイン中の参加者 | 運営 |
| --- | --- | --- | --- |
| 人数・地図・ピン・チャット閲覧 | 可 | 可 | 可 |
| チャット投稿 | 可 | 可 | 可 |
| オフ会ピン作成 | 可（事前予約用途） | 可 | 可 |
| 現在地の募集ピン作成 | 不可 | 可 | 通常の募集は同じ条件 |
| 自分のピンの編集・取消・募集終了 | 可 | 可 | 可 |
| 他者の投稿の削除・利用制限 | 不可 | 不可 | 可 |
| 招待発行 | 可、上限あり | 可、上限あり | 監督可能 |
| ステッカー設置位置・街範囲の管理 | 不可 | 不可 | 可 |

「参加者」は招待を経て利用資格を得た人を指す。街へのチェックインとアカウントへの認証を区別する。停止・制限中は制限内容を優先する。未招待者・未認証者の閲覧範囲と、運営による他者投稿の本文編集の要否は未決定。

## 4. 招待・アカウント・引き継ぎ

| ID | 要件 |
| --- | --- |
| ACC-01 | 招待制とし、参加者も友人を招待できる。 |
| ACC-02 | 運営が招待状況を監督できる。発行回数・使用回数・有効期限の制限と無効化を設ける。具体値・管理表示項目は未決定。 |
| ACC-03 | アカウントタブで名前・アイコン等を設定する。アカウント情報はサーバーに保存する。保存項目・認証方式は未決定。 |
| ACC-04 | 端末間引き継ぎは短時間・一回限りのQRを用いる。 |
| ACC-05 | 元端末で承認し、引き継ぎ先を確認したうえで安全な通信で移行する。完了後、旧端末の認証を無効にする。 |

端末紛失・故障時の復旧、アカウント削除、プロフィール変更の過去投稿への反映は未決定。

## 5. チェックイン・更新・退出

| ID | 要件 |
| --- | --- |
| PRE-01 | 新しいチェックインを開始する際は、毎回現地のNFCタッチを必要とする。過去にタッチした事実だけで自動参加させない。 |
| PRE-02 | チェックインは3時間で失効する。更新がなければ端末からの通知がなくても人数から外れる。 |
| PRE-03 | 有効なチェックイン中にアプリを開いたとき、位置を取得し、まだ街にいるか端末内で判定して更新する。確認用の座標はサーバーへ送らない。 |
| PRE-04 | 更新によって有効期間を3時間延長する。更新による人数の追加は行わない。期限の厳密な起点は提案書で確認する。 |
| PRE-05 | 非常口ボタンで手動退出できる。終了後の再参加はNFC必須。期限切れ後も位置確認だけで復帰しない。 |
| PRE-06 | 退出後も人数・ピン・チャットの閲覧とチャット投稿が可能。アプリを開くだけで再参加しない。 |
| PRE-07 | 遅延・再送された更新で終了済みのチェックインを復活させず、通信再送等による意図しない人数の重複を防ぐ。 |
| PRE-08 | 表示する人数は有効なチェックイン件数。個人の参加者一覧や位置追跡を必須としない。 |

状態の整理：

| 現在の状態 | 出来事 | 結果 |
| --- | --- | --- |
| 未参加・退出済み・失効済み | NFCから新規チェックイン成功 | 有効になる |
| 有効 | 街内と確認でき、更新成功 | 有効期間を更新、人数は同じ |
| 有効 | 手動退出成功 | 終了し、人数から外れる |
| 有効 | 有効期限に到達 | 失効し、人数から外れる |
| 終了・失効 | 位置確認・遅れて届いた更新 | 復帰しない |

バックグラウンド更新の希望はあるがMVP採用は未決定。位置取得拒否・低精度・通信失敗・明確な圏外・アプリを開き続けた場合の確認頻度・オフライン退出の扱いも未決定。通常の固定NFCデータだけでは現地性を厳密に証明できない点を理解して対策範囲を決める。

## 7. ピン・チャット・街の表示

### 7.1 ピン

| ID | 要件 |
| --- | --- |
| PIN-01 | 参加者は共有マップ上にピンを作成できる。オフ会ピンと募集ピンを区別する。 |
| PIN-02 | オフ会ピンはマップで地点を選び、題名・開催日時を設定して事前作成できる。吹き出しに題名と開始までのカウントダウンを表示する。 |
| PIN-03 | オフ会ピンは指定した終了日時で表示を終了する。 |
| PIN-04 | 募集ピンは有効なチェックイン中に、単発で取得した現在地と題名を公開する。公開後の移動を追跡しない。 |
| PIN-05 | 募集ピンは原則20分で終了する。継続する場合は新しく作成する。 |
| PIN-06 | ピンの編集・取消・募集終了ができる。募集ピンは手動終了・時間切れ・チェックアウトで終了する。チェックイン失効も終了に含む。 |
| PIN-07 | 作成頻度と同時掲載数を制限する。本人の操作権限を検証する。具体値は未決定。 |

地図上から消えることとDBからの物理削除を区別し、後者の期限は未決定。公開前の確認、募集ピンの座標編集可否、移動時の挙動、終了済みピンの再編集、イベント説明文、開催中の表示は詳細案で詰める。

### 7.3 UIと画面の構成

合意済みの要素：街の地図・人数・チャット・ピン、非常口、アカウントタブ、全画面でのピン位置選択、募集／オフ会タブ付きの追加シート。

NFC処理中・成功の独自アニメーションを希望。iOSの通常のCore NFCでは読み取り中に標準シートが出るため、独自表示は読み取り完了後のサーバー登録段階に置く案。通信成功前に完了を表示しない。

画面一覧の整理案：招待／登録、街ホーム、全画面ピン位置選択、ピン作成・詳細・編集、アカウント／引き継ぎ、通報、運営。ナビゲーションや細部は未承認。

## 8. 運営・データ・安全性

| ID | 要件 |
| --- | --- |
| OPS-01 | 所有者が運営を担当し、運営用クライアントを使う。 |
| OPS-02 | 招待状況の監督、通報対応、投稿削除・利用制限、ステッカー位置登録を行える。管理画面の詳細は未決定。 |
| SEC-01 | 投稿・ピン・編集削除・管理操作の権限をサーバーで検証する。一般利用者に運営権限を渡さない。 |
| SEC-02 | 接続数・送信頻度・本文長・履歴取得量等の上限を設ける。 |
| DATA-01 | アカウント情報はサーバー保存。通常チャット履歴は30日。継続GPS履歴を集めない。 |
| DATA-02 | 募集時には公開する現在地を送る。チェックインの位置確認は端末内で行う。 |
| DATA-03 | 必要な役割・保存情報を最小化し、漏えい時の被害を抑える。 |

サーバーが扱うデータの整理（実装スキーマではない）：

| データ | 用途 | 保存期間の状態 |
| --- | --- | --- |
| アカウント・認証情報・プロフィール | 本人確認、名前とアイコンの配信、引き継ぎ、制限 | 未決定 |
| 招待と招待関係 | 招待の使用制御、運営の監督 | 未決定 |
| 有効チェックイン | 人数・更新・退出・募集権限 | 有効期間3時間、終了後の削除期限は未決定 |
| 街・設置位置・範囲 | 街の判定と管理 | 更新履歴の保持は未決定 |
| ピン | 予定・募集の公開 | 表示期限は合意済み、物理削除は未決定 |
| チャット | 新着配信と履歴 | 通常履歴30日 |
| 通報・制限・管理記録 | 荒らし対応と誤操作の追跡 | 未決定 |
| 接続等の運用記録 | 障害・不正の把握 | 内容・期間とも未決定 |

招待関係・投稿者情報・募集位置と時刻には攻撃者にとっての価値がある。サーバー保存を最小化しても、招待参加者による表示内容の保存は防げない。滞在とアカウントを分離しても、募集権限や通信情報から相関があり得る。「サーバーが絶対に誰の滞在か知らない」という保証は未確立。

## 9. 主要ユーザーフロー

1. **参加と予定**：招待を受ける → アカウントを設定 → 街の様子を見る → オフ会ピンを作る／予定を確認する。
2. **現地参加**：NFCを読む → チェックイン成功 → 人数へ反映 → 街の中で過ごす。
3. **募集と合流**：有効チェックイン中に募集を作る → 現在地を公開 → 他の参加者が地図で確認 → 手動終了または20分で終了。
4. **継続と退出**：有効期間内にアプリを開いて街内を確認 → 期限更新。手動退出または失効 → 募集も終了。再参加はNFCから。
5. **端末引き継ぎ**：引き継ぎを開始 → 一回限りのQRで接続 → 旧端末で宛先を確認・承認 → 移行成功 → 旧端末を無効化。
6. **運営**：通報・招待状況を確認 → 必要な措置。設置点を変更 → 街の範囲を更新 → 次の位置確認から最新範囲を利用。
